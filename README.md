# SYMON — 실시간 모니터링 시스템

장치 상태를 실시간으로 확인하고, 이벤트 이력과 기간별 통계를 조회하는 업무 시스템입니다. **1인 개발자로 백엔드와 프론트엔드 전체 개발을 담당**했습니다. MQTT 메시지 수신부터 서버 처리, Vue 화면 반영까지 연결했습니다.

> 회사 프로젝트의 기술 경험을 정리한 문서입니다. 원본 소스는 포함하지 않으며, **저장소 이름과 기술 설명을 포함한 외부 공개 허가는 별도로 확인해야 합니다.**

## 담당 역할

- **백엔드:** 업무 API, 데이터 저장·조회, MQTT·WebSocket 연동, 이벤트·알림, 배치·통계 개발
- **프론트엔드:** Vue 3 기반 대시보드·이벤트·보고서·관리 화면, API 연동, 실시간 상태 및 작업 진행 표시
- **시스템 연동:** 메시징, 데이터 저장소, 파일 작업 상태를 애플리케이션 기능으로 연결

## 핵심 기술 스택

| 영역 | 기술 |
| --- | --- |
| 백엔드 | Java 21, Spring Boot 3.1.5, Spring MVC, Spring Security, Gradle |
| 데이터 접근 | MySQL, MyBatis, Spring Data JPA |
| 실시간 통신 | Eclipse Paho MQTT, STOMP over WebSocket, WebSocket |
| 집계·임시 상태 | Spring Batch, DynamoDB SDK, Spring Data Redis |
| 프론트엔드 | Vue 3, Vite, PrimeVue, Vuex, Axios |

버전은 프로젝트 설정 기준입니다.

## 주요 구현 기능

| 기능 | 구현 내용 |
| --- | --- |
| 실시간 상태 조회 | MQTT 수신 메시지를 STOMP로 전달하고 화면 상태 갱신 |
| 연결·수신 감시 | 자동 재연결·재구독, 마지막 수신 시각 기반 지연 감시와 상태 변화 알림 |
| 이벤트 이력·알림 | 이력 저장·조회, 대상 사용자별 WebSocket 알림, Redis 만료 기반 중복 알림 억제 |
| 장치 작업 | 응답 선행 구독, MQTT 요청 발행, 응답 대기·타임아웃 처리, 파일 작업 진행 상태 전달 |
| 통계·보고서 | 누적 데이터 조회·가공, 일·주·월 집계, 보고서 조회 |
| 업무 화면 | 대시보드, 이벤트, 보고서, 계정·조직·장치 관리 API와 화면 연동 |

## 기술적 고민과 개발 경험

- **데이터 성격에 따른 처리 분리:** 실시간 상태 전달, 이벤트 이력 저장, 기간별 집계를 각각의 흐름으로 구현했습니다. 상태 화면에는 STOMP를, 대상 사용자별 이벤트 알림에는 직접 WebSocket 전송을 사용했습니다.
- **연결과 수신 상태 구분:** MQTT 연결 복구 시 구독을 복원하고, 개별 메시지의 수신 지연은 타이머로 관리했습니다.
- **요청 자원 관리:** 응답을 먼저 구독한 뒤 요청을 발행하고, 응답 완료와 타임아웃에 맞춰 구독을 정리했습니다.
- **집계의 동시 처리:** 고정 크기 작업 풀에서 대상별 데이터를 조회·가공하고, 작업 완료를 기다린 뒤 결과를 모아 저장했습니다.

백엔드와 화면을 함께 개발하면서 메시지 수신부터 사용자에게 표시되는 과정까지 다뤘습니다. 특히 이력 저장과 알림 전송의 경계, 응답 대기와 구독 정리, 병렬 작업의 완료와 저장 시점을 함께 고려한 경험을 정리했습니다.

## 공개 범위

이 저장소에는 일반화한 기술 설명만 담았습니다. 회사 원본 코드·SQL·설정, 내부 인프라 정보, DB 스키마, 보안정보, 운영 데이터와 내부 화면·리소스는 제외했습니다. 성능 수치나 운영 성과는 기재하지 않았습니다.

문서는 외부 제공 전 검토용이며, Private 저장소 업로드도 회사가 허용하는 외부 제공 범위인지 별도로 확인해야 합니다.
